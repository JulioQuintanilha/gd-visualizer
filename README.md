## 🔍 Visão Geral do Projeto
Todo modelo de Inteligência Artificial "aprende" da mesma forma: ajustando parâmetros para **minimizar uma função de erro**. O algoritmo que faz isso é o **Gradient Descent**, e ele é Cálculo III puro: derivadas parciais, vetor gradiente e matriz Hessiana.

Este projeto é uma ferramenta interativa e de código aberto que mostra, passo a passo, como diferentes otimizadores navegam por uma superfície \(f(x, y)\) até encontrar um mínimo. O usuário escolhe a função, o ponto inicial e o *learning rate*, e vê a trajetória sobre as curvas de nível, a curva de convergência e a classificação do ponto final.

O público-alvo são estudantes de exatas e de computação que querem entender **por que o Cálculo é a base do treinamento de redes neurais**.
